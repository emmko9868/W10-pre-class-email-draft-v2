Buy the AI plan

Required

In class we'll use an AI helper called Qwen Code. It needs a paid Alibaba Cloud plan, and you each need your own because it's paid for with your own card.

US$10 · about HK$80One month
  1. Turn off your VPN and use your normal Hong Kong connection.
  2. Open the plan page with the link below. Sign up or log in to Alibaba Cloud (the international site, alibabacloud.com).
  3. Add your card. Alibaba Cloud may charge about US$1 first to verify your card. That charge is only a card check and is separate from the plan price. The PDF attached to the email shows each payment screen.
  4. Choose Essential. Before paying, make sure the plan name is Essential, the price is US$10 a month and it comes with 45,000 credits. A new-user discount may make it cheaper, which is OK.
  5. Pay. The region is set to Singapore automatically, which is expected.
  6. Open Token Plan → My Subscriptions. Once your Essential plan is listed there, you're done.

Open the Token Plan page →Check My Subscriptions →

Payment page stuck on loading? Don't pay again. Check My Subscriptions in a new tab first, because the payment has often gone through already.

Card not accepted? Try another payment method such as Alipay. If that fails too, bring your laptop on Wednesday afternoon and we'll sort it out.

The page also shows an API key. Leave it for now; we'll connect it in class. Please don't press Reset or share your account or key with anyone.

4

Connect Figma MCP

Required

Figma MCP lets the AI in VS Code read your Figma designs. Do this step once your student verification has been approved.

This step depends on your Figma student plan.

If it doesn't work, take a screenshot. We'll fix it together on Wednesday or in class.

  1. Install the Figma desktop app if you don't have it yet (figma.com/downloads). Figma in a web browser won't work for this step.
  2. Open the Figma desktop app, log in with your verified student account, and open a design file (or create one: + New → Design file).
  3. Click the Dev Mode button (the </> icon) at the right end of the bottom toolbar.
  4. In the MCP section of the right-hand panel, click + next to Clients.
  5. In the Set up third-party agents for Figma MCP window, click Get Figma integration next to VS Code.
  6. VS Code will open the Figma MCP Server page. Click Install.
  7. A Figma page will open in your browser. Make sure it shows your student account, then click Agree & Allow Access.

It worked if Figma MCP Server is listed under MCP Servers - Installed. To check, click the settings (gear) button at the bottom left of VS Code and choose Extensions.

If it doesn't work, make sure you're using the desktop app, it's up to date, and you're logged in with your verified account. If it still fails, take a screenshot and bring it on Wednesday or to class. Tick this box once you've tried.

If you get stuck

Help

If something doesn't work, don't spend long on it. Take a screenshot and bring it on Wednesday or to class.

I see a different plan name or a different price

Make sure your VPN is off, then reopen the Token Plan page from the link in section 1. The one to buy is Token Plan (Personal) · Essential · US$10 a month. If the price still looks very different, don't pay. Show us a screenshot instead.

The payment page keeps loading

Don't pay twice. Open Token Plan → My Subscriptions in a new tab. If Essential is listed, the payment went through.

I can't enter my card, or it's rejected

Some Hong Kong cards are declined. Try a different card or another payment method such as Alipay. If neither works, come on Wednesday and we'll look at it together.

The region says Singapore. Did I do something wrong?

No. The plan is only sold from the Singapore region, and that is selected automatically. It works from Hong Kong.

My school or work computer blocks installs

That's usually a security setting. Please use a personal computer if you can, and tell us before Thursday if you can't.

Should I install Qwen Code or the starter kit now?

Not yet. We'll do both together in class so that nobody gets stuck halfway.

4

연결: Figma MCP

필수

Figma MCP는 VS Code의 AI가 Figma 디자인을 읽을 수 있게 이어 주는 다리예요. Figma 학생 인증이 승인된 뒤에 해요.

이 단계는 Figma 학생 플랜이 있어야 해요.

안 되면 화면을 캡처해 두세요. 수요일이나 수업에서 같이 해결해요.

  1. Figma 데스크톱 앱이 없으면 먼저 설치해요(figma.com/downloads). 웹 브라우저의 Figma 로는 이 단계를 할 수 없어요.
  2. Figma 데스크톱 앱을 열고 학생 인증 계정으로 로그인한 뒤, 디자인 파일을 열어요(없으면 + New → Design file로 새로 만들어요).
  3. 화면 아래쪽 도구 막대 오른쪽 끝의 Dev Mode 버튼(</> 아이콘)을 눌러요.
  4. 오른쪽 패널의 MCP 칸에서 Clients 옆의 +를 눌러요.
  5. Set up third-party agents for Figma MCP 창에서 VS Code 줄의 Get Figma integration을 눌러요.
  6. VS Code에 Figma MCP Server 페이지가 열려요. Install을 눌러요.
  7. 브라우저에 Figma 페이지가 열려요. 학생 인증 계정이 맞는지 확인하고 Agree & Allow Access를 눌러요.

성공하면 MCP Servers - Installed 아래에 Figma MCP Server가 보여요. 확인하려면 VS Code 왼쪽 아래 설정(톱니바퀴) 버튼을 눌러 Extensions를 골라요.

안 되면 데스크톱 앱인지, 앱이 최신 버전인지, 인증받은 계정으로 로그인했는지 확인해요. 그래도 안 되면 그 화면을 캡처해서 수요일이나 수업에 가져와요. 해 봤으면 체크해요.
